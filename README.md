# DREAM-CATCHER
Il s'agit d'une application qui sert à enregistrer mes rêves. J'écris ou alors je m'enregistre au revéil, et une bulle est générée. A l'intérieur, mon rêve sous forme de petits dessins ( j'aurais voulu une animation mais peut être que je pourrais l'amméliorer avec le temps). L'application a aussi une fonctionnalité " interprétation".
