# DREAM-CATCHER
Il s'agit d'une application qui sert à enregistrer mes rêves. J'écris ou je m'enregistre au réveil, et une bulle est générée. À l'intérieur, mon rêve prend la forme de petits dessins (j'aurais voulu une animation, mais peut-être que je pourrai l'améliorer avec le temps).

L'application propose aussi une fonctionnalité « Interprétation ».
